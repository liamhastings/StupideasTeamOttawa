# Seed profile photos

Drop photos for the hard-coded demo profiles here, then point a profile at it in
`data/seed.ts` with `avatarUrl: photo("your-file.jpg")`.

- Square crops look best (they're shown in a circle). ~400x400 px is plenty.
- Keep each file under ~300 KB so the swipe deck stays snappy.
- Use lowercase names without spaces, e.g. `mia.jpg`.
- Only use photos of people who said yes: the deployed site is public.
